📐 Rechenweg: Mohrscher Spannungskreis & Hauptspannungen
Tangentialspannung (Innendruck)
σ_θ = (Pc · Di) / (2 · s)
σ_θ = (16 bar · 784 mm) / (2 · 8,5 mm) → (16·0,1 MPa · 784) / 17 = 73,8 MPa
Axialspannung (Innendruck)
σ_ax = (Pc · Di) / (4 · s)
σ_ax = (16·0,1 MPa · 784) / (4 · 8,5) = 36,9 MPa
Radialspannung (Innendruck, vereinfacht)
σ_rad = −Pc · 0,1 (Innendruck auf Innenwand)
σ_rad = −16 · 0,1 = −1,6 MPa
Gesamtspannungen inkl. thermischer Anteile
σ_x = σ_ax + σ_th,ax ; σ_y = σ_θ + σ_th,tan ; σ_z = σ_rad + σ_th,rad
σ_x = 36,9 + 339,4 = 376,3 MPa ; σ_y = 73,8 + 339,4 = 413,2 MPa ; σ_z = −1,6 + 339,4 = 337,8 MPa
Mittelpunkt des Mohr-Kreises (x-y-Ebene)
σ_m = (σ_x + σ_y) / 2
σ_m = (376,3 + 413,2) / 2 = 394,8 MPa
Radius des Mohr-Kreises
R = √( ((σ_x − σ_y)/2)² + τ_xy² )
R = √( ((376,3 − 413,2)/2)² + 0² ) = 18,4 MPa
Hauptspannungen (2D in x-y-Ebene)
σ₁,₂ = σ_m ± R ; σ₃ = σ_z
σ₁ = 394,8 + 18,4 = 413,2 MPa ; σ₂ = 394,8 − 18,4 = 376,3 MPa ; σ₃ = 337,8 MPa
Sortierung der Hauptspannungen
σ₁ ≥ σ₂ ≥ σ₃
σ₁ = 413,2 MPa ; σ₂ = 376,3 MPa ; σ₃ = 337,8 MPa
Maximale Schubspannung
τ_max = (σ₁ − σ₃) / 2
τ_max = (413,2 − 337,8) / 2 = 37,7 MPa
Vergleichsspannung (v. Mises)
σ_vM = √( ½ · [(σ₁−σ₂)² + (σ₂−σ₃)² + (σ₃−σ₁)²] )
σ_vM = √( ½ · [(413,2−376,3)² + (376,3−337,8)² + (337,8−413,2)²] ) = 65,5 MPa
Vergleichsspannung (Tresca)
σ_vT = σ₁ − σ₃
σ_vT = 413,2 − 337,8 = 75,4 MPa
Auslastung
Auslastung = σ_vM / σ_zul · 100 %
Auslastung = 65,5 / 129,3 · 100 % = 50,6 % → ✅ Nachweis erbracht
